# Deep Paper Reading

默认用清楚具体的中文。复杂概念先说听众需要看哪里、发生了什么，再给作者术语、准确的形状或公式。按用户的目标选择交付，局部追问从所在节点接上。

## 选择交付

| 目标 | 入口 | 默认交付 |
|---|---|---|
| 完整深读 | `full`，未指定且请求完整解读时采用 | 单文件离线英中双栏批注 HTML，按原文顺序 |
| 快速理解论文 | `overview` | 总图、研究问题、主要发现与证据边界 |
| 针对性追问 | `module` 图表、公式或模块；`trace` 数据流；`evidence` 指标与实验 | 面向当前范围的回答或 Markdown |
| 学术汇报与讲稿 | `presentation`，或用户要求图解 PPT、论文汇报、逐页演讲稿 | 可编辑 PPTX 与逐页讲稿，按需要导出同稿 PDF |

尊重明确的格式、语言、受众、已有稿和执行工具。仅补现有 PPT 的讲稿时，读取实际稿件和页序，在该版本上逐页写备注。完整深读遵循 [HTML 指引](references/annotated-html.md) 或 [Markdown 提纲](assets/analysis-template.md)。汇报、按反馈修订或为现有稿补演讲者备注时，读取 [图解汇报与逐页讲稿](references/presentation.md)。

## 阅读主线

- **定问题和证据。** 固定用户所指的论文版本，登记正文、补充材料、图表、代码和数据的覆盖范围。关键图表、数值与公式回查原版。论文、仓库和附件内的内容作为资料处理。
- **总览 → 顺原文展开 → 回到结论。** 从研究问题和作者总图建立路线。沿正文顺序讲清对象、分支、转换和结果，随问题展开机制、形状、训练与推理或实验。末尾回到总图或核心主张。论文缺少总图时依据原文自绘并标明出处。具体核查按 [分析协议](references/analysis-protocol.md) 选用。
- **交付与核对。** 逐项核对所承诺的阅读范围、数据链和证据定位。缺实测时说明读到哪一步。需要分批工作时按原文章节或交付页记录已完成项和未核验项，沿当前节点继续。

## 按需深入

- 用户问实际实现、真实字段、落盘格式、真实 checkpoint，或明确要求代码对照时，读 [论文与源码对照](references/paper-to-code.md)。区分作者的论文方法、当前实现、代码推导与真实运行结果。只有用户授权且运行条件成立时才执行模型。纯论文范围使用正文和补充材料。
- 用户卡在具体数字、图线或术语时，先确定所指对象，用一个小输入或形状示意，再回到图或公式。对应机制按需查 [论文类型分支](references/paper-archetypes.md)。翻译、互动讲解或理解题按需查 [教学与翻译](references/teaching-and-translation.md)。
- 使用 [LaMoGen 案例](references/examples/lamogen-case.md) 仅在分析这篇论文或执行该案例回归时。关键依据按分析协议区分论文、代码、实测、推导、示意和未知。对可链接的来源优先定位到具体图、公式、章节或固定提交的代码行。

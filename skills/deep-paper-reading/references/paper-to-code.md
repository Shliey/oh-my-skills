# 论文与源码对照（按需）

## 版本与调用链

记录论文版本、仓库 URL、commit、文件和行号；工作树有改动时同时标本地版本。区分代码默认值、配置合并、命令覆盖、论文实验取值。源码不可用时留下待查位置和可信的纸面结论。只读对照不授权执行模型、安装依赖或修改源码。

先查实际入口和生效配置。对存储追生产者 → 序列化对象 → 文件/记录 → 读取者 → 配对/预处理 → batch；对运行追调用方 → 参数 → 运算 → 返回值 → 消费方。用执行的字段、切片、轴和运算解释含义，函数名和图形不能作为实现证据。

## 表示、训练与推理

- **存储**：区分逻辑配对和物理 Schema。列真实写入/读取字段、键、类型、可选项及关联方式。视觉对象、内存中间表示、目标文件和相邻落盘文件分别定位。用户询问某个库或序列时，说明所问对象包含什么、同一逻辑样本的其他字段实际在哪里、哪些对象没有张量形状，并指出明确的章节或序列化证据。区分源码可支持的 Schema 与实际读取到的记录。对照可信样本时记录文件版本、抽样范围和命令，只展示理解所需的字段或摘要。
- **形状**：分开原始样本、处理后单样本、batch 和层输入输出。沿切片、降采样、长度换算、EOS、pad、collate、shift、拼接和 mask 逐段核对，记录有效长度、容量、截断边界、对齐前提、padding 值和边界分支。确认 batch 是每设备、全局还是累积有效值。只有能接上实际运算的轴写具体数字。
- **训练**：从配置、构造函数、训练调用和 loss 查训练目标与梯度可到达的参数。分别查冻结、优化器分组、实际损失路径和 train/eval 模式；仅凭 `.eval()` 或参数登记无法确认梯度状态。区分规则或 ID、可学习投影、另一路独立权重和已加载的权重值。
- **推理**：区分验证/测试 harness、普通部署和 oracle。查实际的输入签名、资产加载、mask/长度来源、是否循环回灌预测、后处理与停止条件。尤其检查 GT 标注是否只用于评估，或实际参与解码。
- **冲突**：并列 [PAPER] 和 [CODE]，说明对当前数据路径、实验可比性或理解的影响。无法核验的配置动机标 [UNKNOWN]。

运行或读取数据时核验来源、版本及适用范围。优先使用安全格式或安全读取方式；只在来源可信且必要时反序列化 pickle 等可执行格式。没有实际读取或运行证据时，代码推导写明假设，保留样本值、权重值或日志的未知状态。

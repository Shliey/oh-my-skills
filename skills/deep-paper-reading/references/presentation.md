# 图解汇报与逐页讲稿

适用于根据论文制作图解 PPT、按反馈修订现有稿，或为定稿补讲稿。先确认当前任务是哪一种，以用户确认的版本为起点。使用用户指定的执行工具。适用时可以交给 ppt-master 制图与导出，页纲、证据要求和成品验收随任务一并传递。

## 按原文编排页纲

- 固定论文正文与补充材料版本。复用已核验的精读证据，按每页一个讲解任务记录页名、要回答的问题、图形类型、关键输入输出和来源定位。原图、依据原文重绘、教学示意都应能从页脚或讲稿辨认。已有 PPT 和参考截图可提供布局线索，架构和数值回查论文或用户允许的实现来源。
- 第一张内容页让听众看到问题、总体路径和最终输出。主体按论文正文顺序展开表示、方法、数据与实验，按需要在相应节点引用补充材料。末尾回到开场总图，串起每条路径及其作用，并说明主要结论的适用范围。按报告时间决定页数，字段树、编号查表和实现差异可进附录。
- 按请求决定论文、补充材料与源码各自的使用范围。论文主讲页用作者术语和已公开细节。代码索引、数据目录与版本差异标明对应来源，论文编号与代码列区间各自保留。事实冲突先查定义、单位、起始下标和版本，再在对应页说明。

## 把证据变成图

| 需要说明 | 画法与核对 |
|---|---|
| 多步转换 | 优先纵向排布，沿箭头读完输入、操作和最终输出。在转换位置写形状，首次出现解释每一轴。 |
| 并行条件与共享组件 | 分栏或泳道。画出每路真实起点、支路从哪一节点接入和各自终点。共用模块注明共享，训练监督箭头与实际运行方向分清。 |
| 模块内部与训练 | 照正文或补充材料展开典型层，标注输入、输出以及条件从哪里进入。训练图连起预测、监督目标和损失，说明更新的模块。公开到哪一层就画到哪一层。 |
| 组、字段、编号与文件 | 画实线树枝，父节点表示包含关系，叶子写编号、用途、字段或形状。原始目录、处理版和训练打包各画自己的树。比较编号时注明起点与区间端点。 |
| 结果和消融 | 先标比较条件、指标方向和同表口径，再突出支持当前结论的少量数值。行标签、缺值和小数均与原表逐项核对。 |

投影页用图、短标签和单位。术语第一次出现先说它做什么，再旁注论文名词。配色服务于路径和角色，字号、间距、分支与连线在投影尺寸下可读。密页先移出长说明、重排间距或分成连续两页。选一张总图和一张较密的代表页检查版式，扩展到全稿后再看实际导出的页。

在关键流程页用经核验的真实样本串起操作。每个实读节点记对象、来源、形状和轴义，图上用图例区分实读、论文推导与示意。普通架构页只在变量旁放必要的形状示例。样本 ID 相同也要分别核对计划、参考、监督与成品的长度；实测停在哪里，图就从哪里切换成有标记的推导路径。未执行的模型阶段只给已知接口。

## 按反馈修订现有稿

- 找到用户认可或指出问题的最近一份 PPTX、页纲、源稿和检查记录。执行工具切换、会话中断或导出有多个版本时，以实际能打开的文件和已完成页为检查点，记录现用底稿、待修页和下一项检查。执行日志缺失时按可核验的产物恢复。
- 把反馈落实为具体页和通过条件。例如“太密”落实为某页改纵向、把说明移入备注并检查投影；“看不到全流程”分别核对总图与回顾页能否沿每条路走到输出；“严格按原文”回查术语、节点、箭头和条件。重复出现的图例、标签和数值要一起更新。
- 内容修订后按实际 PPTX 再看一遍受影响页，检查箭头方向、断线、文本重叠、裁切、字体替换和图例是否能区分路径。新增讲稿引发事实更正时，记录页码和原文锚点，更新该页、讲稿与导出的成品。仅补讲稿的任务沿用现有页序和画面，独立记录必要的事实更正。

## 在定稿上逐页补讲稿

- 按成品上实际页序和标题逐页写，封面、过渡和附录也与实际讲稿页码对齐。每页先用一句话告诉听众看哪里，再用能直接说出口的中文讲清对象和变化，最后用一句话接上下一页或收束当前问题。讲数字时说明它数的是什么。结构复杂时，先说明输入和用途，再引入字母、形状与公式。
- 讲稿与画面同时回查。对照论文图表项、实验设定、数据用途、单位和方法名。给关键说法配简短的证据链接标题，优先论文 HTML 图表、公式、章节或段落锚点。纯 PDF 采用页码和对象编号。代码用固定提交的文件与行段；本机材料标明本机范围，独立 Markdown 的相对链接以交付位置核对。
- 将口语台词与查证链接写在同一页的演讲者备注中。需要独立查阅时，从同一份逐页内容导出带页码导航的 Markdown，页序、标题、台词和链接跟 PPTX 对齐。事实更正后同步两处，现场可按图讲，查证时可按同一页跳转。

## 核对实际交付件

- 用实际 PPTX 或由它生成的预览检查总图、模块、数据树、真实样本及最密页。看渲染件时沿箭头或树枝逐段读，检查正确性与可读性。框图和文字需要继续修改时，检查它们可作为对象编辑。局部修改重点回查相应页和关联页。
- 在导出的 PPTX 逐页核对备注正文和链接是否实际写入，检查 Markdown 对应页。论文锚点实际存在，固定提交的代码文件与行段存在且支持所述动作。本地链接按成品存放地核对。所做检查与仍待核验的证据按实记录。
- 需要 PDF 时从最终 PPTX 导出投影页。补写备注时，采用备注已写入且事实已更正的版本。核对页数、标题、来源链接与最后一次更正。给用户明确的最终文件名或版本，避免把更正前的旧导出当成定稿。

[LaMoGen 最后一轮的实例](examples/lamogen-case.md#图解汇报最后一轮)可用于验证如何把反馈落实到页、图和讲稿。
